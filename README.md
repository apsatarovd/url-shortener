# URL Shortener

Сервис сокращения URL с аналитикой кликов: количество переходов,
устройства, источники.

## Описание проблемы

Длинные URL неудобно передавать, они занимают много места и не
позволяют отслеживать статистику переходов.

**Задача:** создать сервис, который принимает длинный URL,
возвращает короткий код и собирает аналитику кликов (устройства,
источники, количество переходов). Архитектура — два
взаимодействующих микросервиса.


## Два сервиса:

- **link-service** — создание ссылок, редирект, публикация события
  клика в RabbitMQ.
- **analytics-service** — consumer RabbitMQ, запись кликов в
  PostgreSQL, API статистики.

## Функциональные требования

- Создание короткой ссылки из длинного URL.
- Редирект по короткой ссылке (HTTP 302, чтобы браузеры не
  кэшировали и клики не терялись).
- Сбор метаданных клика.
- API для получения статистики: клики по дням, устройствам,
  источникам.
- Авторизация через API-ключ 
 
## Технические требования

- Python 3.12+
- FastAPI
- Poetry (`pyproject.toml`, `poetry.lock`)
- pytest (тесты)
- Docker, `docker-compose up` для запуска
- GitHub Actions (CI)
- Публичный Git-репозиторий
- README с инструкцией запуска

## Нефункциональные требования

- Редирект быстрый за счёт кэширования в Redis.
- Если Redis недоступен — редирект работает через PostgreSQL.
- Если RabbitMQ недоступен — редирект не блокируется.
- Тесты: юнит и интеграционные, покрытие ≥ 70%.
- CI на каждый push (GitHub Actions)
- Запуск через `docker-compose up`.

## Эндпоинты

| Метод | Описание | Авторизация |
|---|---|---|
| POST | Создать короткую ссылку | API-ключ |
| GET | Редирект 302 на оригинал | — |
| GET | Статистика по ссылке | API-ключ |

## Схема БД

PostgreSQL, две таблицы: **links** (ссылки) и **click_events** (клики).
